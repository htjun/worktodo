# Repository Instructions

- Use English only in code, comments, documentation, tests, and metadata.
- Use npm and commit `package-lock.json`. Do not add another package manager or npm workspaces.
- Keep durable product evidence in `docs/research/`.
- Keep Raycast entry points thin and domain code independent of Raycast and MCP adapters.
- Run `npm run verify` before committing.
- Do not publish or add a Git remote without explicit authorization.
